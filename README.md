# Focus Timer

A small browser extension that asks how many minutes you want to use
Facebook or Instagram, then closes the tab when the time is up.

## What it does

- Opens Facebook or Instagram in your browser.
- A popup asks: **"How many minutes?"**
- You pick a time (or type your own).
- A small countdown appears in the top-right corner.
- When the timer reaches zero, the tab closes by itself.
- Next time you open the site, it asks again — no password, no lock.

## How to install

1. Download this project as a ZIP  
   (green **Code** button on GitHub → **Download ZIP**).
2. Extract the ZIP somewhere on your PC.
3. Open your browser:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
   - Brave: `brave://extensions`
4. Turn **ON** the **Developer mode** toggle (top-right or left sidebar).
5. Click **Load unpacked**.
6. Select the extracted folder (the one that contains `manifest.json`).

Done. Open `facebook.com` or `instagram.com` to see it working.
